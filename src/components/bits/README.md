# Componentes de React Bits

Versiones TypeScript + Tailwind copiadas de [React Bits](https://github.com/DavidHDev/react-bits)
(licencia MIT + Commons Clause: se pueden usar en proyectos, no revender los componentes).

| Componente | Dónde se usa en NAR |
|---|---|
| BlurText, RotatingText, ShinyText | Titular y etiqueta del hero (destinos reales rotando) |
| ClickSpark | Buscador del hero y botón "Reservar asiento" |
| LogoLoop | Franja de puntos de encuentro |
| SpotlightCard | Tarjetas de funciones, pasos, seguridad y corredores |
| CountUp | Cifras calculadas con los viajes publicados (sección Corredores) |
| Magnet | Botones de la llamada final |
| Counter | Total de la reserva en el detalle del viaje |
| ElasticSlider | Filtro de aporte máximo en "Buscar viaje" |
| StatusMark | Confirmación en el pase de abordaje |
| HoldButton | Llamada al 911 en "Mi viaje" (mantener pulsado) |
| SwipeToast | Avisos de reserva y publicación |
| GooeyNav | Navegación principal de escritorio |
| Aurora + Noise | Fondo del hero con los colores del logo (solo equipos capaces, ver `useRichEffects`) |
| GradientText | "compartida" en el hero y la llamada final |
| StarBorder | Botón "Buscar viaje" del hero |
| BorderGlow | Barra de reserva activa |
| ScrollReveal | Sección "Por qué NAR" |
| CardSwap | Tarjetas de "Para quién" (escritorio y tablet) |
| ScrollVelocity | Banda de corredores en movimiento |
| GlareHover | Brillo al pasar sobre las tarjetas de viaje |
| DecryptedText | PIN del pase de abordaje |
| DotGrid | Fondo de cabecera en Buscar viaje y Corredores |
| TextType | Sugerencias "Prueba con…" en Buscar viaje |
| GlideSelect | Selector "Ordenar por" |
| SquishSwitch | Interruptores (DUI verificado, aire acondicionado) |
| Radar | Escena de seguimiento en "Mi viaje" |
| LatticeLoader | Pantalla de carga entre vistas |

GlareHover, ScrollReveal y GooeyNav también se ajustaron (tamaño, peso tipográfico y color del marco). SpotlightCard se ajustó a la paleta de Verity (superficie #111113, sin sombra, radio y padding
definidos por quien lo usa).
